# 次工程：許認可・有資格者を静的で出す（沿革と同じやり方）
# 対象: Home copy のみ（path `/`）
# いまライブ: 見出し「許認可・有資格者 / LICENSE」だけ（中身ほぼ空／CMS空）

========================================
ゴール
========================================
許認可5行＋有資格者10行を静的テキストで表示。
CMSは使わない。沿革と同じく「コンテンツ」直下に Text を追加。

========================================
A. Layers で場所を開く
========================================
1. Design mode
2. Layers（左）を開く
3. メインエリア → 許認可まわりの背景／セクションを探す
   名前例: お知らせ_背景 に近い兄弟、または「許認可」「LICENSE」を含む Box
4. その中の「コンテンツ」（または本文が入る空の Box）を選択

※見つからない場合:
   キャンバスで「許認可・有資格者」見出しをクリック
   → Layers でその階層がハイライトされる
   → 同じ親の中の「コンテンツ」／List／no content を探す

========================================
B. CMS空を隠す（沿革と同じ）
========================================
1. List または「no content」／「一覧をみる」があれば
   → 選択 → Hide（目のアイコン）または Delete
2. 「各種許認可と専門資格を保有」だけの空文言があれば Hide でも可

========================================
LAYOUT（沿革と同じ型）
========================================
沿革の実測:
  左: 見出し（約 x81）
  右: 本文（約 x391 / 幅890）
  親: flex row / gap 40px

許認可も同じ型にする:

┌──────────────────────────────────────────────────────────┐
│  許認可・有資格者          │  許認可                      │  有資格者              │
│  LICENSE                   │  免許・許可 5行               │  資格名＋人数 10行     │
│                            │  （幅 ~420）                  │  （幅 ~420）           │
└──────────────────────────────────────────────────────────┘
         ↑ 左カラム（既存見出し）              ↑ 右：Text×2 を横並び（row / gap 40）

かんたん版（Text 1つだけ）:
┌──────────────────────────────────────────────┐
│  許認可・有資格者     │  許認可5行               │
│  LICENSE              │  （空行）                 │
│                       │  有資格者10行             │
└──────────────────────────────────────────────┘

画像（ビル写真）はその下のまま。テキストは見出しの右／画像の上。

========================================
C. 静的テキストを追加
========================================
1. 「コンテンツ」（または見出しの右の空エリア）を選択
2. Add（＋）→ Text → 【許認可】を貼る → Enter
3. Add（＋）→ Text → 【有資格者】を貼る → Enter
4. 2つの Text を横並び:
   - 親 Box を flex / Direction: Horizontal / Gap: 40
   - 各 Text Width おおよそ 420〜450
5. 親 Height が切れる → auto / Hug

※CMS List の中に書かない。List の外・コンテンツ直下。
