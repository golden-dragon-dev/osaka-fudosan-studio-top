# 許認可：いちばん簡単（沿革のコピー流用）
# StudioはChrome専用のため、こちらからは編集できません。
# 沿革で成功した手順の「コピー版」です。

========================================
やること（約3分）
========================================

1. Chromeで Studio を開く（Home copy / path `/`）

2. Design mode

3. 沿革のタイムライン本文（2007.06〜のテキスト）を
   キャンバスでクリックして選択

4. Ctrl+C でコピー

5. 「許認可・有資格者」見出しの右の空きをクリック
   （または Layers で許認可セクションの「コンテンツ」を選択）

6. Ctrl+V で貼り付け
   → 沿革と同じ見た目の Text が1つできる

7. 貼った Text をダブルクリック → 全選択 → 下を貼る → Enter

8. Publish → Update

========================================
うまくいかないとき
========================================
- 貼れない → Add（＋）→ Text → 見出しの右に置いてから貼る
- 中身が消える → CMSのListの中に入っている。Hideして、Listの外に置き直す
- 切れる → 親Boxの Height を auto
- 「一覧をみる」が出る → Hide

終わったら「done」と送ってください。ライブ確認します。
