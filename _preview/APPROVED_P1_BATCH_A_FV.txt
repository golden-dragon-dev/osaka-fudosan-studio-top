# 承認済み実装｜Batch A：ファーストビュー再整理
# 対象: Home copy / path `/`
# 方針: ブランド＋見出し1＋短文＋CTA。SPでフォームが主役にならない

========================================
ゴール（似たサイトの型）
========================================
1画面目で伝わるもの:
  - 会社名（ブランド）がヒーロー級
  - 見出し1つ
  - 短いリード1文
  - CTA（電話 or 相談）
  - 全面に近いビジュアル

SPでやりたいこと:
  - 大きな問い合わせフォームはヒーローを圧迫しない
  - 「まずはお問い合わせ」→ #contact は維持

========================================
A1. ヒーロー見出し・リード（文言は維持でOK）
========================================
見出し（維持）:
物件の価値を見極め、
最適な用途へ転換し、収益を最大化する。

リード（ヒーロー直下・短く）:
使われていない不動産を再生し、地域や社会に必要とされる場所へと変えていきます。

※長い会社紹介文はヒーロー外（その下の本文）に残す

========================================
A2. SP：フォーム位置（重要）
========================================
いま: ヒーロー右に大きいフォーム → SPで縦に長く第一印象を圧迫

手順:
1. Design → Mobile（375）
2. ヒーロー内のフォーム（お気軽にお問い合わせください）親Boxを選択
3. どちらか:
   【推奨】Mobileだけ Hide（目を閉じる）し、下の #contact 位置のフォーム／CTAで足りる構成にする
   【代替】フォームをヒーロー外・事業の上 or CTA直前へ移動（Mobileレイアウト）
4. Desktopではフォームを残してOK（Breakpointで出し分け）

※フォームの ID: contact は残す（リンク切れ防止）
  Hideする場合は、見える方のフォーム親にも id=contact を付ける

========================================
A3. ヒーロー余白・階層（Mobile）
========================================
1. 見出しの Font をヒーローで最大、リードは一段小さく
2. 「まずはお問い合わせ」バー直下の余白: 24〜40
3. 数字帯（2007 / 6 / 10資格）はヒーロー内下部にコンパクトに
4. 可能なら4つ目を追加:
   大阪 / 港区夕凪
   （既存3つを複製してラベル変更）

========================================
A4. CTAの見え方
========================================
ヒーロー付近に残す導線（SP）:
  - まずはお問い合わせ → #contact
  - または tel:0665776161（ヘッダー電話でも可）

下の紺CTAは後工程で「電話する／相談する」二択化（Batch D前後）
