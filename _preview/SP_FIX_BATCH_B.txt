# Batch B：余白・文字・リンク・フッター
# 前提: Batch A 完了（不要文削除済み）
# Studio → Home copy → Design → Mobile（375）で作業
# 1項目ごとに Enter 確定 → 最後に Publish → Update

========================================
B1. イントロ上の余白（指摘2）
========================================
場所: 「まずはお問い合わせ」バーの直下〜
      青見出し「使われていない不動産を再生し…」のあいだ

手順:
1. Mobile幅
2. 青見出し（またはその親Box）をキャンバスで選択
3. 右パネル Spacing:
   - Padding Top を減らす（大きい数字 → 24〜40）
   - Margin Top も大きければ同様
4. バー直下に空のスペーサーBoxがあれば Height を小さく／Hide
5. Desktop幅に戻して極端に詰まっていないか確認
   ※余白は Mobile だけ小さくできるなら Breakpoint: Mobile で調整

========================================
B2. 許認可の可読性（指摘4）
========================================
場所: 【許認可】【有資格者】の本文Text

1. Content mode → 許認可テキストをダブルクリック
2. 全文を下の New に差し替え → Enter
3. Design mode → 同じTextを選択
4. Font size: 13〜14（見出しより明らかに小さく）
5. Line height: 1.7〜1.8
6. Color: 濃いグレー（#333前後）。見出しの紺と同じにしない

========================================
B3. 沿革の可読性（指摘8）
========================================
場所: 沿革のタイムライン本文

1. Content → 沿革本文をダブルクリック
2. 下の New を貼る → Enter
3. Design → Font size を許認可本文と同じ（13〜14）
4. Line height 1.7〜1.8
5. 日付だけ少しグレー／小さめにできるなら日付行のみ調整

========================================
B4. 電話表示＋ワンクリック（指摘9・10）
========================================
【表示】紺CTA右の白い電話ボックス

Old（1行）:
06-6577-6161 / 06-6577-6160

New（3行）:
TEL 06-6577-6161
FAX 06-6577-6160
受付時間 平日9:00-18:00

※受付が別Textなら番号だけ2行にして受付は触らない

【TELリンク】
1. Design → 「TEL 06-6577-6161」のText（または電話アイコン＋番号のBox）を選択
2. 右パネル Link → URL:
   tel:0665776161
3. FAX行にはリンクを付けない

【資料請求ボタン】
1. 「資料請求 / 問い合わせ」白ボタンを選択
2. Link を変更:
   いま: /contact など別ページ
   推奨: ページ内フォームへ
3. ヒーロー右のフォーム（お気軽にお問い合わせください）の親Boxを選択
4. 右パネルで ID / Anchor に: contact
5. 資料請求の Link を: #contact
6. 上部「まずはお問い合わせ」バーも同様に #contact

========================================
B5. フッター高さ（指摘11）
========================================
1. Mobile幅
2. フッター全体（薄い背景の大きなBox）を選択
3. Padding Top / Bottom を半減（例: 80→32〜40）
4. 中の Gap / 各要素の Margin を縮小
   - ロゴ〜住所
   - 住所〜ナビ3つ
   - ナビ〜SNS
   - 個人情報〜コピーライト
5. SNS（X/IG/FB）が実アカ無しなら Hide 推奨（高さ削減＋仮感解消）
6. Desktopでも極端に潰れていないか確認

Publish
========================================

2. スマホ実機で確認:
   [ ] イントロ上の余白が減った
   [ ] 許認可・沿革が読みやすい
   [ ] TELタップで発信
   [ ] 資料請求でフォームへ移動
   [ ] フッターが短くなった
