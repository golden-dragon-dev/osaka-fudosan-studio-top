# CTA電話ボックス｜レイアウト直し（Old → New）
# 対象: Pages → Home copy｜path `/`
# 文言はOK。箱の中が左寄り＆右が空いて見える問題だけ直す。

========================================
原因
========================================
白い電話ボックスは「番号＋受付時間」の2行用。
FAXを3行目に足したため、中身が左に寄り右が空く。

おすすめ: 会社概要06と同じく TEL／FAX を1行にする（見た目が元の2行に戻る）

========================================
Studio 操作ルール
========================================
1. Pages → Home copy
2. Content mode ON で文言、Design mode でサイズ／揃え
3. キャンバスで編集 → Enter → Publish → Update
4. 確認: https://white682608.studio.site/

========================================
A. 文言直し（いちばん簡単・推奨）
========================================
場所: 紺CTA右・白い電話ボックス内の番号テキスト

Old:
06-6577-6161
FAX 06-6577-6160

New:
06-6577-6161　／　06-6577-6160

※会社概要06と同じ書き方。TELとFAXが1行になる。

手順:
1. Content mode ON
2. 番号テキストをキャンバスでクリック → 青枠
3. もう1回クリックで編集
4. Ctrl+A → New を貼る → Enter
5. 外側クリック

受付時間（変更なし）:
受付時間 平日9:00-18:00

完成イメージ（2行）:
  phone  06-6577-6161　／　06-6577-6160
         受付時間 平日9:00-18:00

========================================
B. 揃え直し（Aのあと、まだ右が空くとき）
========================================
1. Design mode に切替
2. 白い電話ボックス全体をクリック（青枠）
   ※アイコンや文字ではなく「白い角丸の箱」を選ぶ
3. 右パネル Layout:
   - Direction: Horizontal（横）のまま
   - Justify: Center（中央）
   - Align: Center（中央）
4. 中の「番号＋受付」のまとまり（Textの親Box）があれば
   それも Align: Center
5. 箱の Height が余る／切れる → Height: Hug / Auto
6. 上の「資料請求 / 問い合わせ」白ボタンと
   幅・角丸・余白が揃っているか目視

========================================
C. 3行のまま残したい場合（Aをやらないとき）
========================================
1. Design mode
2. 白い電話ボックスを選択
3. Height を Hug / Auto（または少し高くする）
4. Justify: Center / Align: Center
5. 番号テキストの Font size を1段階小さく（任意）
6. Padding 左右を均等に（例: 左右 24〜32）

※上の資料請求ボタンと同じ高さに無理に合わせない。
  中身が多いので電話側が少し高くてOK。

========================================
Publish
========================================
1. Publish → Update
2. ライブで右空きが消えているか確認

終わったら「done」と送ってください。
