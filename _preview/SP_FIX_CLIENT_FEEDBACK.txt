# クライアント指摘 11点 → Studio修正ガイド（SP重点）
# 対象: Home copy（path `/`）
# 公開: https://white682608.studio.site/
# 画面確認: Design → 右上で Mobile 幅（375）に切替してから作業

方針:
- 文言はほぼOK。今回は「見た目・余白・操作」の直し。
- フルリデザインではなく、テンプレ残渣の削除＋SP調整＋リンク動作。
- 費用内で対応可能な範囲（フル新規デザインではない）。

優先順: 1 → 10 → 3/5 → 2/6/7/11 → 4/8 → 9

========================================
1. ハンバーガーが使えない
========================================
原因: SPでハンバーガーが見えるが、メニュー開閉／ページ内リンクが未設定の可能性。

手順:
1. Design mode → Mobile幅
2. ヘッダー右のハンバーガー（三本線）を選択
3. 右パネルで「Menu / Drawer / Overlay」に紐づいているか確認
   - 無い場合: Add → Menu または既存テンプレの Menu Box を再接続
4. メニュー内リンクをページ内アンカーに設定:
   - 会社概要 → #company（会社概要セクションのID）
   - 事業内容 → #business
   - 許認可・資格 → #license
   - 沿革 → #history
   - お問い合わせ → #contact または /#contact（フォーム位置）
5. 各セクション見出しBoxを選択 → 右パネル ID を上記どおり付与
6. Publish → Update → スマホ実機でタップ確認

※Desktopナビは動いていても、Mobile用MenuのOpenトリガーが切れていることが多い。

========================================
2. 余白が気になる（1枚目＝イントロ上）
========================================
場所: 「まずはお問い合わせ」バーの下〜青見出しのあいだの白余白

手順:
1. Mobile幅
2. 青見出し「使われていない不動産を…」の親Boxを選択
3. Spacing → Padding Top / Margin Top を減らす（例: 80→24〜40）
4. 「まずはお問い合わせ」バー直下のスペーサーBoxがあれば Height を縮小 or Hide
5. PC幅でも極端に詰まないか確認（Breakpointsで Mobile のみ小さく）

========================================
3. このロゴはどうなる想定？（2枚目＝SALFORD等）
========================================
場所: 「各種許認可と専門資格を保有しています」下の横スクロール／ロゴ列
→ 清掃テンプレのダミーロゴ（SALFORD & CO. 等）。実在の取引先ロゴではない。

対応（推奨）: セクションごと Hide または Delete
1. Design → 当該ロゴ列（または親Box）を選択
2. Hide（目アイコン）または Delete
3. 見出し「各種許認可と専門資格を保有しています」も不要なら一緒に Hide
   ※許認可の正式リストは下の LICENSE セクションに既にある

クライアント説明: 「テンプレートの仮ロゴのため削除します」

========================================
4. 許認可が読みにくい・大きい・ベタ打ち（3枚目）
========================================
場所: 【許認可】【有資格者】の静的テキスト

手順:
1. Content/Design → 許認可テキストを選択
2. Font size: 本文相当に下げる（例: 18〜20 → 13〜14／Mobile）
3. Line height: 1.7〜1.8
4. 色: #333 前後（見出しの紺より一段落とす）
5. できれば2カラムや区切り:
   - 【許認可】と【有資格者】を別Textに分け、間に Gap 16〜24
6. 全角スペースだらけなら、短い改行形式に直す:

【許認可】
宅地建物取引業者免許証
大阪府知事（4）第53408号
建設業許可
大阪府知事（般-4）第129413号
…
（1項目＝2行）

========================================
5. ここはなんでしょうか？（4枚目）
========================================
場所: 許認可と会社概要のあいだ
- 薄い建物写真＋「各種許認可と専門資格…」の薄い文字
- 大きな白余白
→ テンプレの装飾／旧セクションの残骸。情報としては LICENSE と重複。

対応: その写真ブロック一式を Hide/Delete
余白も親の Padding を詰める

========================================
6. 「会社情報のご案内です」は必要？（5枚目）
========================================
不要。テンプレ定型文。

手順: テキスト選択 → Delete または Hide
見出し「会社概要 / COMPANY」の直下に表が来るように余白調整

========================================
7. 「これまでの歩みをご紹介します」も同様・余白过大（6枚目）
========================================
同様に Delete/Hide 推奨。
沿革見出しとタイムライン本文の Gap を 16〜24 に詰める。

========================================
8. 沿革がベタ打ち・フォント不一致（6枚目）
========================================
手順:
1. 沿革本文 Text を選択
2. Font size を許認可・会社概要の本文と同じに揃える（13〜14）
3. 行間を空ける（各イベントのあいだに空行1つ）
4. 理想: 日付と本文を分ける／日付だけ小さめ・グレー

貼り直し例:
2007.06
大阪市中央区にて株式会社大坂不動産事務所　設立

2020.02
エイブルネットワーク加盟

…

========================================
9. 電話番号のテキストが出ている（7枚目）
========================================
白い電話ボックス内で TEL/FAX がただの文字。
はみ出し気味にも見える。

手順:
1. 番号テキストを選択
2. Font size を少し下げる（Mobileで収まるサイズ）
3. 幅が足りなければ TEL と FAX を2行に:

TEL 06-6577-6161
FAX 06-6577-6160
受付時間 平日9:00-18:00

※「テキストとして見えている」＝リンク化されていない問題 → 10と同時対応

========================================
10. ボタン／番号のワンクリック動作（7枚目）
========================================
想定動作:
A. 「資料請求 / 問い合わせ」→ フォーム位置へスクロール（または contact）
B. TEL 06-6577-6161 → tel:06-6577-6161（発信）
C. FAX 06-6577-6160 → 発信不要。表示のみ、または別テキスト

現状:
- 資料請求リンクは /contact へ（別ページ）。TOP内フォームへ飛ばす方がよい場合あり
- tel: リンクが無い

手順:
【資料請求】
1. 白ボタン「資料請求 / 問い合わせ」を選択
2. Link をページ内 #contact（ヒーローのフォーム、または下部フォーム）に変更
3. フォーム親Boxに ID: contact を付与

【電話】
1. Design → 番号「06-6577-6161」を選択（または電話白ボックス全体）
2. Link → tel:0665776161（ハイフン無し推奨）
3. FAXはリンクしない（テキストのみ）か、別行にして非リンク

【まずはお問い合わせ】バー
- 同様に #contact へ

========================================
11. フッターが高すぎる（8枚目）
========================================
手順（Mobile）:
1. Footer 親Box を選択
2. Padding Top/Bottom を半減（例: 80→32〜40）
3. ロゴ〜住所、住所〜ナビ、ナビ〜SNS の Gap を縮小
4. ナビ3リンクの各 Margin を縮小
5. SNS（X/IG/FB）が仮なら Hide も可（実アカ無ければ削除推奨）
6. 個人情報とコピーの余白も詰める

========================================

========================================

[ ] イントロ上の大きな白余白が減った
[ ] SALFORD等ダミーロゴが消えた
[ ] 許認可・有資格者の写真残骸が消えた
[ ] 「会社情報のご案内です」「これまでの歩みを…」が消えた or 余白適正

[ ] フッターが1画面を埋め尽くさない
