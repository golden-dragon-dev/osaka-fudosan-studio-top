# 事業カードがページ外にはみ出すとき（Design mode 修正）
# 原因: 3列用の横並びのまま6枚にした → 幅が足りず右（または下）へはみ出す

========================================
いちばん確実な直し方（2行×3列）
========================================
1. Home copy を開く
2. Content mode OFF → Design mode
3. キャンバスで「事業内容」のカード群の親ボックスをクリック
   - 6枚すべての外側の枠（カードを包んでいる Box）
   - Layers で探すなら「業務方針」付近の、カードが並ぶ親
4. 右パネル Box タブで確認・変更:

   A) Direction
      - いま row（横一列）なら → row-wrap に変更
      - または column にして縦積みでも可（見た目は弱め）

   B) Width（親）
      - 親を 100% にする（画面幅に収める）

   C) Gap
      - 16〜32 程度（詰まりすぎ・空きすぎを調整）

5. カード1枚ずつをクリックして Width を揃える:
   - おすすめ: 各カード Width = 32% または 380px 前後
   - 6枚とも同じ数値にする
   - これで 3枚で1行 → 自動で折り返して 2行になる

6. セクション（事業内容の背景 Box）の Height が固定なら:
   - Height を auto にする（下にはみ出して切れるのを防ぐ）
   - Padding 下を少し増やす（80〜120）

7. デスクトップ（1280）で確認 → Tablet / Mobile もざっと見る
8. Publish → Update

========================================
もっと簡単な代替（レイアウトを2段に分ける）
========================================
もし wrap がうまくいかない場合:
1. 親の中でカードを「上段3枚」「下段3枚」の2グループに分ける
2. 上段用 Box（横並び・カード3枚）を Duplicate
3. 下段に 障害福祉 / ホテル / メディア を入れる
4. 親は column（縦）+ Gap

========================================
やってはいけないこと
========================================
- はみ出したカードをドラッグで無理に左へ寄せるだけ
  （再読み込みや他ブレイクポイントでまた外れる）
- Content mode だけで直そうとする（これは Design の仕事）

========================================
直ったかのチェック
========================================
- デスクトップ: カードがページ右端より内側に全部見える
- 横スクロールバーが出ない
- 2行×3列（またはきれいな折り返し）になっている
- ライブ https://white682608.studio.site/ で同じ
