# B｜再生の進め方 → Desktop 横3列 / Mobile 縦1列
################################################################################

いまの構造（重要）:
  Layer 名: 「企業ロゴ」または「Company Logo Section」
  中身の兄弟（だいたいこの並び）:
    - 見出し Text「再生の進め方」
    - Text「01 見極める…」
    - Text「02 転換する…」
    - Text「03 運営する…」
    - （空の Box がある場合あり → 触らなくてよい）

目標レイアウト:
  Desktop (Default): 見出しは全幅1行 → その下に 01/02/03 が横3列
  Mobile: 全部縦1列（今のまま）

※いちばん確実なのは「見出しはそのまま」「01/02/03 だけを Box で包んで横並び」です。


----------------------------------------
B-1. セクションを見つける
----------------------------------------
1. Design mode
2. Layer パネルを開く
3. メインエリア の中を探す:
     「企業ロゴ」または「Company Logo Section」
4. クリックして選択（キャンバスに青枠）
5. 中に「再生の進め方」と 01/02/03 が見えるか確認


----------------------------------------
B-2. ★重要：Studio に「Wrap in Box」は無い
----------------------------------------
公式の名前は Group（グループ化）です。

  右クリック → 【Group】
  またはキーボード: Ctrl + G（Mac は ⌘ + G）

「Wrap」というメニュー項目は出ません。探さなくてOK。


----------------------------------------
B-3. 01/02/03 を Group する（推奨）
----------------------------------------
理由:
  親全体を横並びにすると、見出しも横に並んで崩れる。
  ステップ3つだけ Group すると安全。

手順:
1. Design mode
2. 幅を Default（PC）にする
3. Layer パネルを開く
4. 「01 見極める」をクリック
5. Ctrl を押しながら「02 転換する」「03 運営する」もクリック
   （Mac は Command）
   → 3つが同時選択（青枠が3つ）
6. どれか1つの上で 右クリック → 【Group】
   または Ctrl + G
7. Layer に新しい親 Box が増える → それを選択
8. 右パネル Box タブ:
     Direction: →（横）または wrap（折り返し）アイコン
     Gap: 24〜32
     Width: 100%

子の 01/02/03 それぞれ:
  Width: 約 30%〜32%

見出し「再生の進め方」:
  Group に入れない（外のまま）
  Width: 100%
  Layer 順でステップ親の上にあること


----------------------------------------
B-4. Group しなくてもできる方法（いちばん簡単）
----------------------------------------
Group が不安なときはこちらだけでOK。

1. 幅を Default（PC）
2. Layer で「企業ロゴ」または「Company Logo Section」を選択
3. 右パネル Direction: wrap（折り返し）アイコン
   ※ → 横 の隣にある wrap アイコン
4. Gap 水平・垂直: 32
5. 見出し「再生の進め方」を選択 → Width: 【100%】
   ← ここを忘れると見出しと 01 が同じ行になる
6. 01 / 02 / 03 をそれぞれ選択 → Width: 【30%】〜【32%】

崩れたらすぐ Ctrl+Z。


----------------------------------------
B-5. Mobile は縦1列（必ず上書き）
----------------------------------------
1. 幅を Mobile にする
2. Group した場合 → その親 Box を選択
   Group しなかった場合 → 「企業ロゴ / Company Logo Section」を選択
3. Direction: ↓（縦 / column）
4. 01/02/03 の Width: 100%

チェック（エディタ）:
[ ] Mobile: 見出し → 01 → 02 → 03 の縦並び
[ ] Default: 見出し1行 → その下に 01 | 02 | 03


----------------------------------------
B-6. 見た目の微調整（任意）
----------------------------------------
- Gap 24〜40
- Font size は 14 / Weight 400 のまま
- 空の薄いピンク Box は触らなくてよい

# つまずいたとき
################################################################################

Q. Direction の row-wrap ラジオが押せない
A. 親の小さな丸ではなく、その行全体（ラベル付近）をクリック。
   それでもダメなら column → row の順で一度切り替えてから row-wrap。

Q. 見出しと 01 が同じ行に並んだ
A. 見出し Width を 100% にする。または B-2 の Wrap in Box に切り替える。

Q. Mobile でも横並びになった
A. 幅を Mobile にしてから、ステップ親の Direction を column に上書き。

Q. Font 一覧に Noto Sans JP が無い
A. 他の本文（会社紹介など）を選ぶ → Font 欄を見る → 同じ書体名を説明文にも適用。
   プロジェクトには既に Noto Sans JP が入っている。

Q. Publish してもライブが古い
A. Ctrl+Shift+R。それでもダメなら URL の末尾に ?v=2 を付けて開き直す。

Q. 間違えて消した
A. すぐ Ctrl+Z。ベースやメインエリアは消さない。
