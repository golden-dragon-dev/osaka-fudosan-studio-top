# ワイヤー1a寄せ（現行契約・テンプレ改修の範囲）
# ページ: Home copy（`/`）
# 公開: https://white682608.studio.site/
# 方針: フル新規ではなく、見た目をワイヤーの「スッキリ縦長LP」に近づける
################################################################################

ワイヤー1aの理想順:
  HERO（見出し＋写真＋問い合わせCTA）
  → 事業内容（6）
  → 会社概要
  → 許認可・有資格者
  → 沿革（タイムライン感）
  → お問い合わせ（TEL/FAX/地図）

いまの課題:
  - ヒーローに大きなフォームがあり、ワイヤーより「テンプレ感」が強い
  - セクション順が 事業 → 許認可 → 会社概要 → 沿革（ワイヤーは 会社→許認可→沿革）
  - カード感・装飾が多く、ワイヤーの余白感と違う

========================================
毎回の基本
========================================
Design mode（Content OFF）
変更後: Publish → Update
確認: Ctrl+Shift+R

################################################################################
# W1｜ヒーローをワイヤー寄りに（最優先・見た目が大きく変わる）
################################################################################

目的: 第一画面を「見出し＋ビジュアル＋CTA」にする

1. Layer → メインエリア → FV_背景
2. 「お気軽にお問い合わせください」の白いフォーム親Boxを選ぶ
3. Default（1280）のまま → 右パネルで Hide（目アイコン）
   ※すでに Mobile で Hide 済みなら、Default でも Hide
4. 「まずはお問い合わせ」CTAボタンは残す（#contact へ）
5. 見出し「物件の価値を見極め…」が大きく見えるか確認

チェック:
[ ] Desktop でヒーロー内フォームが見えない
[ ] CTA は残っている
[ ] 見出しが第一印象の主役

################################################################################
# W2｜セクション順をワイヤーに近づける
################################################################################

Layer の上下ドラッグで並び替え（メインエリア直下）:

目標順（事業のあと）:
  1. 紹介_背景（事業内容）※そのまま
  2. 会社概要（BusinessPolicyBackground / #company）
  3. 許認可（Work Achievement 等 / LICENSE が入っている親）
  4. 沿革（Announcement Background / #history）

いま 許認可が会社概要の上なら、会社概要レイヤーを許認可の上へ。

チェック:
[ ] スクロール順: 事業 → 会社概要 → 許認可 → 沿革

################################################################################
# W3｜事業カードの「テンプレ感」を弱める
################################################################################

1. 事業コンテンツ内のカード親を選ぶ
2. 影（Shadow）が強ければ弱める / 0
3. 角丸が大きければ小さめ（例: 0〜4px）
4. 余白（Padding / Gap）を少し広げてワイヤーの風通しに

やりすぎ注意: 画像差し替えは素材があるときのみ

################################################################################
# W4｜沿革のタイムライン感
################################################################################

1. 沿革本文（12件）を選ぶ
2. Size 14〜16 / Weight 400 / Line 160〜180
3. 親Boxの Height が切れていたら Hug / Auto
4. 可能なら左に細い線 or 年月だけ強調（できる範囲で）

################################################################################
# W5｜余白・見出しの強弱
################################################################################

各セクション見出し（事業内容 / 会社概要 / 許認可 / 沿革）:
  - Size を他見出しと揃える
  - 上下 Margin を少し広げて「詰まり感」を減らす

################################################################################
# 終わったら
################################################################################
1. Publish → Update
2. Desktop 1280 / Mobile 375 で確認
3. チャットで「done wireframe」と送る

やらなくてよい（追加見積もり領域）:
- フル新規デザイン
- 写真の全面差し替え（素材なし）
- 左固定ナビ（1b）への作り直し
