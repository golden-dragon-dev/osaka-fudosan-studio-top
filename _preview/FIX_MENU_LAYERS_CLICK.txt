# あなたのLayers画面どおり・クリック手順
# ヘッダー → メニュー の中だけ触る

========================================
A. お問い合わせボタン（ボタンリンク）
========================================
1. Layers でこれをクリック:
   ヘッダー → メニュー → 【ボタンリンク】
2. 右パネル Link（リンク）を開く
3. いま /menu や /contact や Page not found なら削除
4. 入力: #contact
5. Enter

========================================
B. ハンバーガー本体（モバイルメニュー）
========================================
1. Layers でこれをクリック:
   ヘッダー → メニュー → 【モバイルメニュー】
2. 右パネルに Link があり /menu なら → Remove Link / クリア
3. 右パネル上部のタブを探す:
   Style / Layout / その右や下に
   「Interactions」または稲妻アイコン「+」
4. + を押す
   - On: Click
   - Do: Show  または Toggle
5. Target（対象）を選ぶ画面が出たら:
   Layers の 【ナビゲーション_背景】 を指定
   （目が閉じているあの行）

※ Interactions タブが見えないとき:
   右パネル一番上の「…」やパネル切替で
   Design / Content ではなく box 選択中か確認。
   それでも無い → C案へ。

========================================
C. Interactionsがどうしても無い場合（簡易）
========================================
1. 【ナビゲーション_背景】の目アイコンをクリックして「表示」にする
2. Mobile幅プレビューで、ナビが画面に出るか確認
3. はみ出す／常時出る場合は:
   - ナビゲーション_背景を選択
   - Position: Fixed / 画面いっぱい
   - 背景を白や紺にしてオーバーレイ風に
4. 中の 【ナビゲーション】 内リンクをすべて #:

   会社概要 → #company
   事業内容 → #business
   許認可・資格 → #license
   沿革 → #history
   お問い合わせ → #contact

5. ハンバーガー（モバイルメニュー）に
   Click → Hide も付けられると閉じられる

========================================
D. ナビ内リンク（必ず）
========================================
1. Layers:
   ヘッダー → メニュー → ナビゲーション_背景 → ナビゲーション
2. 中の各メニュー項目を1つずつ選択
3. Link を上の # に変更
4. /about /service /works /news は使わない

========================================
E. Publish
========================================
Publish → Update
スマホでハンバーガー確認
