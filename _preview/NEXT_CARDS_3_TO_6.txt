========================================
A. Design mode でカードを複製（先に構造）
========================================
1. Studio で Pages → Home copy を開く
2. 「Turn off content mode」または Content を OFF → Design mode にする
3. キャンバスを「事業内容 / BUSINESS」までスクロール
4. 3枚目のカード（解体業）をクリックして選択
   - 画像＋タイトル＋説明文がひとまとまりの「カード」になるよう、いちばん外側のボックスを選ぶ
   - Layers パネルで親子が分かれている場合は、カード全体の親 Box を選ぶ
5. 複製（どれか1つ）:
   - ショートカット: Ctrl + D
   - または右クリック → Duplicate
   - または上部メニューの Duplicate
6. 同じ操作をあと2回（合計でカードが 3→6 になるまで）
   - 1回目の複製 = 4枚目用
   - 2回目の複製 = 5枚目用
   - 3回目の複製 = 6枚目用
7. 並び確認:
   - 左→右（または上→下）が 1〜6 の順になるようドラッグで並べ替え
   - はみ出し・重なりがあれば、親の横並び（wrap / gap）を少し調整
8. ここで Publish しなくてよい（テキスト差し替え後にまとめて）

========================================
B. Content mode でテキスト差し替え（4〜6枚目）
========================================
1. Content editing mode（鉛筆）を ON
2. キャンバスで 4枚目カードのタイトルをクリック → 編集
3. Ctrl+A → 下の New を貼る → Enter
4. 同じカードの本文も同様 → Enter
5. 5枚目・6枚目も同じ
