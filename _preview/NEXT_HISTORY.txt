========================================

========================================
沿革セクションに日付＋出来事の行を複数出す。
CMSは使わず静的テキストでOK。

おすすめ（短め・6行）※時間がなければこれ:

＋ 既存があれば:
2007.06　大阪市中央区にて株式会社大坂不動産事務所　設立

フル版（余裕があれば）は下の「全文リスト」

========================================
A. いま何があるか確認
========================================
1. Design / Content どちらでも、沿革までスクロール
2. 「一覧をみる」の上に行があるか見る
   - 1行だけ（2007.06…）ある → Bへ（その行を Duplicate）
   - 行が無い → Cへ（テキストボックスを新規追加）

========================================
B. 既存の1行がある場合（Duplicate）
========================================
1. Content mode OFF → Design mode
2. 2007.06 の行（日付＋文章のセット）を選択
3. Ctrl+D で必要な本数まで複製
   - 短めならあと5回（合計6行）
   - フルならあと10回前後
4. 縦に並ぶか確認。親の Height が固定なら auto に
5. Content mode ON
6. 各行をキャンバスで書き換え → Enter
   （日付と本文が別テキストなら両方）

========================================
C. 行が無い場合（新規で作る）
========================================
1. Design mode
2. Add（＋）→ Text を2つ追加（日付用・本文用）
   または 既存の似た行（会社概要の1行など）を Duplicate して沿革エリアへドラッグ
3. 日付＋本文を横並び（row）または「日付 / 本文」1テキストにまとめても可
4. 1行できたら Ctrl+D で本数を増やす
5. Content mode で文言を貼る → Enter

かんたん版（1テキスト1行）:
例: 2020.02　エイブルネットワーク加盟
