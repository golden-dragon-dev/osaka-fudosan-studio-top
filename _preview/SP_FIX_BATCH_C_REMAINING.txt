# Batch C 残り：ハンバーガー内リンクの差し替え
# ID自体はすでにOK。メニュー項目のURLがまだテンプレの別ページのまま。

ライブ確認:
OK:
  #business / #license / #company / #history / #contact すべて存在
  フッターの 会社概要・事業内容・許認可 → #〜 済み

NG（要修正）:
  ヘッダー／ハンバーガー内のリンクがいまだ:
    会社概要     → /about
    事業内容     → /service
    許認可・資格 → /works
    沿革         → /news
    お問い合わせ → /contact
  ※別ページが空／無いため「メニューが使えない」ように見える
  フッター「沿革」も /news のまま残っている可能性

========================================
手順（正確）
========================================
1. Design → Home copy → Mobile（375）
2. ハンバーガーを一度開いた状態で編集できるなら開く
   （開けない場合は Layers でヘッダー内の Menu / Nav を探す）

3. メニュー内の各テキスト／リンクを1つずつ選択し、
   右パネル Link を次に変更:

   会社概要     → #company
   事業内容     → #business
   許認可・資格 → #license
   沿革         → #history
   お問い合わせ → #contact

4. Desktop用ナビ（同じリンクを共有していることが多い）も
   同じ # になっているか確認

5. フッターの「沿革」も #history に

6. Publish → Update

7. スマホ実機:
   - ハンバーガーが開く
   - 各項目で該当セクションへ移動
   - 空の /about 等に飛ばない

※Interaction: メニューを開くトリガーが切れている場合は
  ハンバーガー選択 → Interactions → Toggle Menu / Open Overlay を確認

終わったら「done C2」と送ってください。
