# Batch A｜ファーストビュー再整理（Old → New）
# 対象: Pages → Home copy｜Type: Home｜path `/`
# 必ずキャンバス上で編集（右サイドバーだけだと Publish に乗らない）

========================================
Studio 操作ルール（毎回これ）
========================================
1. Pages → Home copy（Type: Home / path `/`）を開く
2. 右上で幅を切替: Mobile 375 ／ Desktop
3. Content mode = 文字／ Design mode = Hide・余白・ID
4. キャンバスをクリック → 青枠 → 編集 → Enter
5. Publish → Update
6. 確認: https://white682608.studio.site/

========================================
どこか（場所）
========================================
ページ最上部（ヒーロー）:
  - 大見出し
  - 短いリード
  - 右（PC）／下（SP）の問い合わせフォーム
  - 「まずはお問い合わせ」バー
  - 数字帯（2007年／6／10資格）

========================================
1. 短いリード（ヒーロー用）
========================================
場所: ヒーロー内・大見出しの直下

Old（長い／ヒーローに入りすぎている場合）:
株式会社大坂不動産事務所は、物件の価値を見極め…（長い紹介文）

New（短く）:
使われていない不動産を再生し、地域や社会に必要とされる場所へと変えていきます。

手順:
1. Content mode ON
2. ヒーロー内のリード文をクリック → 青枠
3. もう1回クリックで編集
4. Ctrl+A → New を貼る → Enter
5. 外側クリック

※大見出しは触らない（変更なし）:
物件の価値を見極め、
最適な用途へ転換し、収益を最大化する。

========================================
2. 長い紹介文の置き場
========================================
場所: ヒーローの外（「まずはお問い合わせ」バーの下〜事業の上）

New（ここに置く／既にあればそのままでOK）:
株式会社大坂不動産事務所は、物件の価値を見極め、最適な用途へ転換し、収益を最大化する会社です。使われていない不動産を再生し、グループホームなどの運営を通じて、地域や社会に必要とされる場所へと変えていきます。ホテル事業（bessam）やメディア事業にも取り組んでいます。

手順:
1. ヒーロー内に長い文が残っていたら Cut
2. バー下の本文位置に Paste → Enter
3. ヒーロー内には短い New（上記1）だけ残す

========================================
3. SPだけフォームを隠す（いちばん重要）
========================================
場所: 「お気軽にお問い合わせください」の白いフォーム一式

Old:
SPでもヒーローに大きなフォームが出る

New:
SPではフォーム非表示／PCでは表示のまま

手順:
1. Design mode
2. 右上を Mobile（375）にする
3. フォーム全体の親Boxをクリック（入力欄1つではなく外枠）
4. 右パネルの目アイコン → Hide
5. Desktop に戻して、フォームがまだ見えるか確認
   ※Desktopまで消えたら Hide を戻し、Mobile幅のときだけ再Hide
6. 下の相談エリア（または残したフォーム）の親Boxに
   ID: contact
7. 「まずはお問い合わせ」「資料請求」の Link が #contact か確認

========================================
4. 余白（Mobile）
========================================
場所: 「まずはお問い合わせ」バーの下〜青見出し／リード

Old: 大きな白余白
New: Padding Top 24〜40

手順:
1. Design → Mobile
2. 青見出し or リードの親Boxを選択
3. Spacing → Padding Top / Margin Top を 24〜40 に
4. Desktop で極端に詰まっていないか確認

========================================
5. 数字帯に4つ目（任意）
========================================
場所: ヒーロー内の円（2007年／6／10資格）

Old: 3つ
New: 4つ目を追加

追加内容:
上: 大阪
下: 港区夕凪

手順:
1. Design → 「2007年」の円を選択
2. Duplicate（複製）
3. Content で上・下の文字を New に変更
4. 並び・隙間を調整

※できなければスキップしてOK

========================================
Publish
========================================
1. Publish → Update
2. スマホで確認:
   [ ] 第一画面に巨大フォームが無い
   [ ] 短いリードが見える
   [ ] 「まずはお問い合わせ」→ 相談位置へ移動

終わったら「done A」と送ってください。ライブ確認後、Batch B を同じ形式で出します。
