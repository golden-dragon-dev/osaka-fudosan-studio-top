# 大坂不動産｜次にやる手順（シンプル版）
# ページ: Studio → Pages → Home copy（path `/`）
# 公開先: https://white682608.studio.site/
################################################################################

========================================
毎回こうする
========================================
1. Chrome で Studio を開く
2. Home copy を開く
3. 左下の鉛筆＝ Content mode を ON
4. キャンバス上の文字をクリック
5. Old を消して New を貼る
6. キーボードで Enter を押す（これで保存される）
7. 全部終わったら右上 Publish → Update

----------------------------------------
STEP 7｜事業内容の説明文
----------------------------------------
場所: 「事業内容」「BUSINESS」のすぐ下（空いていればそこに Text を追加）

もし Text が無ければ:
1. Content を一旦 OFF（Design mode）
2. Add → Text
3. 「事業内容」の下に置く
4. Content mode に戻して文字を入れる

物件の取得・再生から、建設・解体、そして福祉・ホテル・メディアでの運営まで。用途転換を一気通貫で支えます。

################################################################################
# ⑤ 再生の3ステップを足す（時間があれば）
################################################################################

----------------------------------------
STEP 9｜Design でブロック追加
----------------------------------------
場所: 会社紹介文の下、事業内容の上

1. Design mode
2. Add → Box（親）
3. 中に Text を4つ（見出し＋3つ）

見出し New:
再生の進め方

① New:
01 見極める
物件の価値と可能性を見極め、最適な用途を描きます。

② New:
02 転換する
建設・解体など社内体制で、用途転換に必要な更新を進めます。

③ New:
03 運営する
福祉・ホテル・メディアなど、地域に必要とされる形で運営します。

各文字のあと Enter
Desktop は横3列、Mobile は縦1列
