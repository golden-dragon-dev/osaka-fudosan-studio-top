========================================
どこにあるか
========================================
ページを下にスクロール:
  会社概要（01〜08）の下
  → 「沿革 / HISTORY」の真上
  → 画面中央にグレー文字「Type Something」

位置イメージ:

  ……会社概要 08……

            Type Something     ← ★ここ（中央）

  沿革 / HISTORY     |  2007.06 …
  これまでの歩み…   |  2020.02 …

  （紺の問い合わせCTA）

※許認可セクションの横ではありません。
  前回追加したテキストが「沿革の上」に入っています。

========================================
Studioエディタでの探し方（最短）
========================================
1. Chromeで Design Editor → Home copy（path `/`）
2. Design mode のまま、キャンバスを下へスクロール
3. 「沿革」見出しが見えたら、そのすぐ上を見る
4. 「Type Something」をクリックして選択

見つからないとき:
  A. ズームを 72% → 100% に戻す（見やすい）
  B. Layers → メインエリア → お知らせ_背景 を開く
     → 「Type Something」または無名の Text を探す
  C. Ctrl+F（ブラウザ検索）は効かないことが多い
     → キャンバスで「沿革」までスクロールが確実

========================================
書き換え手順
========================================
1. Content mode ON（文章編集）
2. 「Type Something」をダブルクリック
3. 全選択（Ctrl+A）→ 下を貼る → 外側をクリック（Enterだけだと改行になる）
4. Content mode OFF
5. Publish → Update
