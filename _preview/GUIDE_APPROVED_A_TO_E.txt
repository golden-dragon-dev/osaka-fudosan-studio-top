========================================
毎回の基本操作（必ず守る）
========================================
1. Chromeで Studio を開く
2. Pages → Home copy（path `/`）
3. 右上で表示幅を切替:
   - Mobile: 375（SP指摘対応・余白はここで）
   - Desktop: 1280前後（PC崩れ確認）
4. Design mode = レイアウト・Hide・ID・Link・サイズ
   Content mode = 文字の書き換え
5. キャンバス上で編集（右サイドバーだけだと Publish に乗らないことあり）
6. 文字編集後は Enter → 外側クリックで確定
7. 1まとまり終わったら Publish → Update
8. スマホ実機 or ブラウザ幅375で確認

※Breakpoint:
  Mobileだけ変えたい余白・Hideは、対象を選んだ状態で
  「Mobile」幅にしてから数値変更（Desktopに影響しにくい）

# BATCH A｜ファーストビュー再整理
################################################################################

----------------------------------------
A-0. いまの問題
----------------------------------------
- SPでヒーロー内の大きなフォームが縦に長く、第一印象を圧迫
- 余白が大きく、ブランド／見出しの優先度が弱い
- 数字帯が3つ（理想は4つ目「大阪・港区夕凪」）

----------------------------------------
A-1. ヒーロー文言の整理
----------------------------------------
【Design → Content】

(1) メイン見出し（大きく残す）
場所: ヒーロー中央〜左の大見出し
維持:
物件の価値を見極め、
最適な用途へ転換し、収益を最大化する。

(2) 短いリード（見出しの直下・1〜2行）
場所: 見出しのすぐ下
New（短く）:
使われていない不動産を再生し、地域や社会に必要とされる場所へと変えていきます。

(3) 長い会社紹介文
場所: ヒーローの外（青い帯の下など、スクロール後）
→ ヒーロー内に入っている場合は、下のセクションへ移動 or そのまま下に残す
文言例（維持可）:
株式会社大坂不動産事務所は、物件の価値を見極め、最適な用途へ転換し、収益を最大化する会社です。使われていない不動産を再生し、グループホームなどの運営を通じて、地域や社会に必要とされる場所へと変えていきます。ホテル事業（bessam）やメディア事業にも取り組んでいます。

手順:
1. Content mode ON
2. 長い紹介がヒーロー内なら選択 → Cut
3. イントロ本文の位置に Paste（または既存本文をこの文に置換）
4. Enter 確定

----------------------------------------
A-2. SPだけヒーローフォームを隠す【最重要】
----------------------------------------
場所: 「お気軽にお問い合わせください」の白いフォーム一式

手順:
1. Design mode
2. 表示を Mobile（375）にする
3. フォーム全体の親Boxをクリック（青枠）
   ※入力欄1つではなく、フォーム全体を包むBox
4. 右パネルの目アイコン（Hide）で非表示
   または Display: none / Hide on Mobile
5. 表示を Desktop に戻す → フォームがまだ見えるか確認
   - Desktopで消えていたら: Hideを解除し、Mobile幅だけで再Hide
6. ID確認:
   - 見える問い合わせ先（下の紺CTA付近 or 残したフォーム）の親に
     ID: contact
   - 「まずはお問い合わせ」「資料請求」の Link が #contact のままか確認

チェック:
[ ] Mobileでヒーローに巨大フォームが無い
[ ] Desktopでフォームが残っている（残す方針の場合）
[ ] #contact タップで何か見える位置へ行く

----------------------------------------
A-3. ヒーロー余白・サイズ（Mobile）
----------------------------------------
1. Mobile幅
2. 大見出しを選択 → Font size を画面で収まる最大付近に
3. リードを選択 → 見出しより 4〜6px 小さく
4. 「まずはお問い合わせ」バー直下〜見出しの Padding Top を 24〜40 に
5. 数字帯（2007年／6／10資格）の親 Gap・Margin を詰める

----------------------------------------
A-4. 数字帯に4つ目を追加（可能な場合）
----------------------------------------
いま: 2007年・設立 / 6・事業領域 / 10資格・有資格在籍

追加:
大阪
港区夕凪

手順:
1. Design → 既存の円（例: 2007年）を選択
2. Duplicate（複製）
3. Content で文字を変更:
   上: 大阪
   下: 港区夕凪
4. 4つが横に並ぶよう親の Gap / Wrap を調整
5. Mobileで4つが窮屈なら:
   - 2×2グリッド
   - または Font を少し小さく

※複製が難しい場合は後回しでOK（A必須ではない）

----------------------------------------
A-5. Publish（Batch A）
----------------------------------------
1. Publish → Update
2. スマホで確認:
   [ ] 第一画面がフォームだらけでない
   [ ] 見出しが読める
   [ ] まずはお問い合わせ → 相談位置へ
3. 完了したらチャットで「done A」

# BATCH B｜事業6つの見せ方（転換の流れ）
################################################################################

----------------------------------------
B-0. ゴール
----------------------------------------
事業が「 explainer カードの羅列」ではなく、
不動産 → 建設／解体 → 福祉 → ホテル → メディア
の転換ストーリーに読めること。

推奨並び（左上から）:
1 不動産業
2 建設業
3 解体業
4 障害福祉事業（↗ kakeru）
5 ホテル事業（↗ bessam）
6 メディア事業（↗ osakakiten）

----------------------------------------
B-1. カード並び替え
----------------------------------------
1. Design mode
2. 各事業カードをドラッグして上の順に並べる
   （または Layers で順番変更）
3. 6枚とも揃った幅・ギャップか確認（Mobileは1列）

----------------------------------------
B-2. セクション見出し直下に一文追加
----------------------------------------
場所: 「事業内容 / BUSINESS」の直下

New:
物件の取得・再生から、建設・解体、そして福祉・ホテル・メディアでの運営まで。用途転換を一気通貫で支えます。

手順:
1. 見出し下を選択 → Add → Text → 上記を貼る → Enter
2. Font: 本文サイズ（13〜15） / 色はグレー系

----------------------------------------
B-3. 各カード本文（短く・転換が伝わる）
----------------------------------------
Content mode で各カード説明を確認・必要なら置換:

【1 不動産業】
買取・開発・賃貸など、物件の価値を見極めた取引を行います。

【2 建設業】
大阪府知事許可（般-4）第129413号。再生に必要な工事体制を社内に持ちます。

【3 解体業】
石綿調査・各種主任者資格を有する体制で対応。次の用途への更地化・更新を支えます。

【4 障害福祉事業】
グループホーム「かける」を運営。不動産を地域に必要とされる暮らしの場へ転換します。

【5 ホテル事業】
「bessam」日本橋・難波を開業。物件の用途を宿泊へ転換し、運営まで行います。

【6 メディア事業】
Webメディアの企画・運営。事業と地域の接点を情報発信で支えます。

※リンクは維持:
  障害福祉 → https://kakeru.asia/
  ホテル → https://www.bessam.jp/
  メディア → https://osakakiten.com/

----------------------------------------
B-4. 外部3カードの強調（任意）
----------------------------------------
1. 福祉／ホテル／メディアのカードに「公式サイト」テキスト or 矢印が無ければ追加
2. Link がカード全体 or ボタンに付いているか確認（新タブ可）

----------------------------------------
B-5. Publish →「done B」
----------------------------------------

# BATCH D｜再生の3ステップ ＋ CTA二択
################################################################################

----------------------------------------
D-1. 「再生の3ステップ」ブロック追加
----------------------------------------
置き場所（推奨）:
  イントロ（会社紹介文）の下 〜 事業内容の上

手順:
1. Design → 事業内容セクションの直前を選択
2. Add → Box（横並び用の親）
3. 中に Text を3つ（または Box×3）

見出し（セクション）:
再生の進め方

英字（任意）:
PROCESS

3つの中身:

【01 見極める】
物件の価値と可能性を見極め、最適な用途を描きます。

【02 転換する】
建設・解体など社内体制で、用途転換に必要な更新を進めます。

【03 運営する】
福祉・ホテル・メディアなど、地域に必要とされる形で運営します。

レイアウト:
- Desktop: 横3列 / Gap 24〜40
- Mobile: 縦1列
- 番号は大きく、本文は14前後
- カード枠（薄い線）は最小限。装飾しすぎない

----------------------------------------
D-2. 紺CTAを二択に
----------------------------------------
場所: 沿革下の紺ボックス

左テキスト（維持可）:
不動産の買取・活用、各事業に関するご相談はお電話にてお気軽にお問い合わせください。

右:
【ボタン1】資料請求 / 問い合わせ → Link: #contact
【ボタン2・電話ボックス】
表示:
TEL 06-6577-6161
FAX 06-6577-6160
受付時間 平日9:00-18:00

Link:
- TEL行のみ tel:0665776161
- FAXはリンクなし
- 資料請求は #contact
