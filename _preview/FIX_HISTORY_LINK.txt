# 沿革リンク修正（/news → #history）
# 対象: Home copy（path `/`）
# いまライブ: 「沿革」が2箇所とも /news のまま（空ページ）
# ゴール: 両方とも #history にして沿革セクションへ飛ぶ

========================================
Studio 操作ルール
========================================
1. Pages → Home copy
2. Design mode
3. キャンバスまたは Layers で対象を選択
4. 右パネル Link を変更
5. Publish → Update
6. 確認: https://white682608.studio.site/

※ #history の先（沿革セクション）の ID はすでに付いている想定。
  無い場合は沿革セクション親Boxに ID: history を付ける。

========================================
場所1：ヘッダー／ハンバーガー内の「沿革」
========================================
Layers パス（前回の画面どおり）:
  ヘッダー
   └ メニュー
      └ ナビゲーション_背景
         └ ナビゲーション
            └ （中の項目）沿革

手順:
1. Layers を開く
2. ヘッダー → メニュー → ナビゲーション_背景 → ナビゲーション
3. 目アイコンが閉じている場合は、編集中だけ目を開けてもOK
4. 中の「沿革」テキスト／リンクを1回クリック（青枠）
5. 右パネル Link を確認

Old:
/news

New:
#history

6. 入力したら外側クリックで確定

見つからないとき:
- キャンバス上部で検索「沿革」
- または Ctrl+F（Studio内検索）で「沿革」
- ヒットしたリンクのうち href が /news のものを全部直す

========================================
場所2：フッターの「沿革」
========================================
場所: ページ最下部フッターのナビ
  （会社概要 / 事業内容 / 許認可・資格 の並びにある「沿革」）

手順:
1. キャンバスを一番下までスクロール
2. フッターの「沿革」をクリック（青枠）
3. 右パネル Link

Old:
/news

New:
#history

4. 外側クリックで確定

Layers で探す場合:
  フッター →（ナビ／メニュー）→ 沿革

========================================
ID確認（リンク先）
========================================
1. 沿革セクション見出し「沿革」またはその親Boxを選択
2. 右パネル ID / Anchor が history か確認
3. 空なら入力: history
4. 先頭に # は付けない（ID欄は history のみ）

========================================
Publish と確認
========================================
1. Publish → Update
2. スマホまたはブラウザで https://white682608.studio.site/ を開く
3. 確認:
   - ヘッダー／メニューの「沿革」→ 沿革セクションへ移動（/news に行かない）
   - フッターの「沿革」→ 同様

終わったら「done」と送ってください。ライブ再確認します。
