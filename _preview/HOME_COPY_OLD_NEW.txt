# Home copy のみ（Pages → Home copy｜path `/`）
# 必ずキャンバス上で編集（右サイドバーだけだと Publish に乗らない）

========================================
Studio 操作ルール（毎回これ）
========================================
1. Pages → Home copy（Type: Home / path `/`）を開く
2. Content editing mode（鉛筆）を ON
3. キャンバスをスクロールして対象テキストを画面中央付近に出す
   ※ヒーローの大きな枠が下に被るので、対象がヒーローの下に隠れない位置にする
4. キャンバステキストを1回クリック（青枠で選択）
5. もう1回クリック（またはダブルクリック）で文字編集に入る
6. Ctrl+A → New を貼る → Enter（1テキストごと必ず Enter）
7. 次のテキストへ。編集中はページをリロードしない／別ページへ行かない
8. 全部終わったら Publish → Update
9. 確認: https://white682608.studio.site/

※右パネルの入力欄は「見え方用」。最終はキャンバスの文字が公開される。
